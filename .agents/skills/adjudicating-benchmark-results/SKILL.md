# Adjudicating benchmark results

You are a fresh adjudicator, not the runner, primary judge, or reviewer.

1. Open `ADJUDICATE.md` first and follow it exactly.
2. Resolve only `disagree` subjective criteria without an adjudication.
3. Read the output and rubric and record an independent score before reading
   either prior conclusion.
4. Never change objective scores or runner files.
5. Preserve primary and reviewer data; write the final resolution under
   `adjudications` and in `report/adjudications/`.
6. Run `node tools/validate.js` before finishing.
