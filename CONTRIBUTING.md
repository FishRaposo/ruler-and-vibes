# Contributing

Ruler & Vibes is a personal model-chooser kit, not an official leaderboard.
Keep roles separate and preserve the zero-infrastructure contract.

| Role | Protocol | Project skill |
|---|---|---|
| Model under test | `RUN.md` | `running-the-benchmark` |
| Primary judge | `JUDGE.md` | `judging-benchmark-results` |
| Second-pass reviewer | `REVIEW.md` | - |
| Fresh adjudicator | `ADJUDICATE.md` | `adjudicating-benchmark-results` |
| Metajudge | `METAJUDGE.md` | - |
| Parallel-form author | `AUTHOR.md` | `generating-parallel-tests` |

Runners must never read evaluator protocols, rubrics, report data, or design
docs. Reviewers do not replace primary scores. Adjudicators resolve only
material disputed criteria. Metajudges diagnose patterns and never edit scores.

## Configuration and generated files

- `tiers.json`: Core/Extended source of truth.
- `benchmark.json`: labels, domains, day suites, and Core default.
- `report/config.js` and the marked `RUN.md` suite block: generated by
  `node tools/sync-config.js`.
- `report/tests.js`: generated by `node tools/gen-tests.js`.

Do not hand-edit generated sections. Parallel forms remain Full-only.

## Data changes

`report/data.js` must remain schema version 2 and contain raw evidence only.
Preserve existing primary, independent reviewer, and adjudicator values. Every
review verdict includes the reviewer's own 0–10 score. Never persist
computed totals, effective scores, statuses, coverage, or aggregates.

Do not commit personal runs or judgment dumps unless they are intentional
fixtures or approved samples.

## Required checks

```text
node tools/sync-config.js
node --test
node tools/validate.js
node tools/canary-audit.js
node tools/calibrate.js
node tools/browser-qa.js
```

After generation, `git diff --exit-code -- RUN.md report/config.js` should be
clean. Calibration is diagnostic and must never mutate test or tier sources.

Out of scope: package managers, frameworks, CDNs, APIs, hosted leaderboards,
live-web evaluations, and harness-specific permission systems.
