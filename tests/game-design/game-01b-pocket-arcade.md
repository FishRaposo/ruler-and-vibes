## Task

Build a playable skill toy that lives in a single HTML file. Pick any
genre you like (timing, aim, sorting, memory, ...), but it must have: a
running tally shown while you play, a losing condition you can actually
reach, and a way to start a fresh attempt without refreshing the page.

## Deliverables

- `toy.html` — one file, inline CSS and JS, with the controls spelled
  out on screen before or during play.

## Constraints

- No external resources or libraries. Pick keyboard OR pointer controls
  (say which). Must open straight from `file://`. A newcomer should grasp
  and enjoy it within a minute.
